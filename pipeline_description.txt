================================================================================
1. PROJECT OVERVIEW
================================================================================

What the repository does
------------------------
Research project on *Cornus sericea* L. transcriptome sequencing and annotation,
focused on identifying and characterizing bifunctional 3-dehydroquinate
dehydratase / shikimate dehydrogenase (DQD/SDH) gene variants.

The repository stores:
  - Final transcriptome assembly and annotation products (FASTA, GFF3, BLAST
    best-hit tables, BUSCO summary, GO/KEGG tables).
  - Downstream analysis of five annotated DQD/SDH loci plus a manually curated
    splice variant (DQD/SDH1.1 vs DQD/SDH1.2).
  - Phylogenetic and comparative analyses (alignments, IQ-TREE trees, identity
    matrices, publication figures).
  - Reproducible scripts (Python, Bash, R) and an R Markdown report (Analysis.Rmd).

Main technologies, frameworks, and languages
--------------------------------------------
  - Languages: R (Analysis.Rmd), Python 3 (bin/*.py), Bash (bin/*.sh).
  - Document/reporting: R Markdown -> HTML (Analysis.Rmd, output: html_document).
  - Bioinformatics (documented in README, not all run inside this repo):
      trans2express, fastqc, NanoPlot, cutadapt, fastp, rnaQUAST, BUSCO,
      minimap2, samtools, seqkit, BLAST/DIAMOND, eggNOG-mapper, TransDecoder,
      Clustal Omega (clustalo), IQ-TREE (iqtree2 or iqtree).
  - External web tools (README): KEGG KAAS, ProtParam, NCBI ORFfinder, iTOL,
    TargetP, WoLF PSORT, DeepLoc 2.0, PredSL, ChloroP (subcellular localization).
  - R packages (Analysis.Rmd): ggplot2, ggpubr, tidyverse, dplyr, paletteer,
      stringr, ggtree, reshape2, viridis, readxl, reticulate, ape, gplots,
      ggplotify, patchwork, ggseqlogo, Peptides, zoo, skimr, Biostrings,
      ggmsa (optional install via devtools), readr.
  - Python packages (scripts): pandas, goatools (GO_analysis_from_eggnogg_data.py),
      Bio (Biopython in seq_similarity.py only).

Raw sequencing reads, assembly intermediate directories, and most reference
databases are NOT stored in this repository.

3. FULL PIPELINE FLOW

PHASE A: Sample preparation and sequencing (README only; not in repo)
-----------------------------------------------------------------------
Inputs:
  - *Cornus sericea* tissues: young/mature leaves, immature fruits, buds, flowers
    (Moscow, July 2024).
Data sources / accessions (README):
  - NCBI BioProject PRJNA1466783
  - SRA: SRR38625913-SRR38625918

Processing (documented, not scripted in repo):
  - RNA extraction (RNeasy), DNase (TURBO DNA-free), Qubit, Bioanalyzer QC.
  - Illumina TruSeq Stranded mRNA, PE 2x101 bp (NovaSeq 6000).
  - ONT cDNA (Mint kit, barcoded), SQK-LSK114 library, Guppy 6.5.7 basecalling,
    NTproc custom pipeline (https://github.com/shelkmike/NTproc/).

Outputs:
  - Raw per-sample SR and LR FASTQ files .

PHASE B: Read QC and trimming 
-------------------------------------------
Inputs: raw SR.fastq.gz, LR.fastq.gz 

Tools:
  - fastqc (SR), NanoPlot (LR)
  - cutadapt -a A{100} (LR poly-A removal)
  - fastp (SR adapter/poly trimming)

Trimmed SR and LR FASTQ files deposited in NCBI database.

PHASE C: De novo transcriptome assembly 
---------------------------------------------------------
Inputs:
  - concatenated SR
  - concatenated LR

Command (README):
  python trans2express.py -1 ... -2 ... --long_reads ... -t 30 -m 120 -o Assembly

Algorithm/tool:
  - trans2express hybrid short+long read assembler/annotator.

Key outputs (copied or symlinked into Files/ in this repo):
  - Files/final.clust_transcripts_longest_iso.fasta
  - Files/final.clust_proteins_longest_iso.fasta
  - Files/final.clust_cds_longest_iso.fasta
  - Files/final.clust_annotation_longest_iso.gff3


PHASE D: Assembly quality assessment 
--------------------------------------------------------------
Inputs: assembly FASTA/CDS; reference genome; reads.

Steps:
  1) rnaQUAST vs *Cornus florida* reference (GCF_030987335.1).
  2) BUSCO (--mode tran) on CDS vs eukaryota, eudicots, viridiplantae odb10.
  3) minimap2 read mapping (SR and LR) + samtools flagstat.

Outputs in repo:
  - Files/busco.csv (summarized BUSCO metrics for plotting in Analysis.Rmd #1)
  - plots/busco_statistics.png (from Analysis.Rmd)
  - rnaQUAST_report, BUSCO metrics


PHASE E: Functional annotation 
-------------------------------------------------------
Inputs:
  - Files/final.clust_transcripts_longest_iso.fasta (and proteins for eggNOG)
  - External databases: UniProt plants (reviewed), RefSeq plant proteins, NCBI nr
    (viridiplantae subset), eggNOG, KEGG (via KAAS and/or eggNOG fields)

E1. Batch splitting (README):
  seqkit split -s 1 final.clust_transcripts_longest_iso.fasta -O split_batches
  (split_batches/ not in repository)

E2. UniProt (bin/Uniprot.blastx.best.sh):
  - blastx vs uniprot_plants_db, e-value 1e-10, best hit per query
  - Repo result: Files/uniprot_best_hits.txt

E3. RefSeq (bin/Refseq.blastx.best.sh):
  - diamond blastx per batch vs refseq_proteins.dmnd
  - Repo result: Files/refseq_best_hits.txt

E4. NCBI NR (bin/NR_anno.sh):
  - blastx per batch vs viridiplantae nr DB
  - Repo result: Files/NR_best_hits_combined.txt

E5. eggNOG-mapper:
  - Input: final.clust_proteins_longest_iso.fasta
  - Repo file: Files/final.clust_proteins_longest_iso.emapper.annotations

E6. GO parsing (bin/GO_analysis_from_eggnogg_data.py):
  - Reads emapper annotations; uses db/go-basic.obo via goatools
  - Writes (when run from repo root): GO_terms_with_ontology.csv,
    GO_terms_highest_level_per_transcript.csv, GO_annotation.txt
  - Repo copies: Files/GO_terms_highest_level_per_transcript.csv,
    Files/GO_annotation.txt

E7. KEGG :
  - KEGG KAAS web submission of protein sequences.
  - Repo KEGG tables: Files/KEGG_annotation_per_transcript.csv,
    Files/KEGG/KEGG_pathways.txt, Files/KEGG/*_list.txt lookup files

E8. Merge into GFF3 (bin/gff3_annotation.py):
  - Reads Files/final.clust_annotation_longest_iso.gff3
  - Merges RefSeq > UniProt > NR product names; adds GO and KEGG attributes
  - Writes annotated_final.gff3 and unannotated_transcripts.txt
  - Repo annotated GFF3 location: Files/annotated_final.gff3
  - Repo unannotated list: unannotated_transcripts.txt 

Business logic:
  - Annotation priority for protein product: RefSeq > UniProt > NR
  - GO terms attached from Files/GO_terms_highest_level_per_transcript.csv
  - KEGG KO/Pathway/Module/Reaction from Files/KEGG_annotation_per_transcript.csv

Outputs (plots/):

PHASE G: DQD/SDH identification and curation (README + Files/DQD_SDH/)
----------------------------------------------------------------------
Inputs:
  - Files/annotated_final.gff3 (grep for "bifunctional 3-dehydroquinate
    dehydratase/shikimate dehydrogenase")
  - Files/final.clust_transcripts_longest_iso.fasta
  - Files/final.clust_proteins_longest_iso.fasta

Steps:
  G1. GFF3 grep/awk -> five mRNA loci with UTR/CDS coordinates (README table).
  G2. Sequence extraction (awk on FASTA) -> DQD/SDH candidate sets.
  G3. Per-sample minimap2 alignments for IGV splicing inspection (README; BAMs
      not in repo). Screenshots: IGV/CserDQD_SDH1.png ... CserDQD_SDH5.png,
      CserDQD_SDH1_all.png.
  G4. Manual naming: DQD/SDH1-5; intron-retention isoform -> DQD/SDH1.2.

Repo sequence sets:
  - Files/DQD_SDH/DQD_SDH_possible_nt.fasta
  - Files/DQD_SDH/DQD_SDH_possible_pr.fasta

G5. Splice-interval removal for DQD/SDH1.1 (intron retention correction):
  python3 bin/splice_interval_to_fasta.py \
    -i Files/DQD_SDH/DQD_SDH_possible_nt.fasta \
    -o Files/DQD_SDH/DQD_SDH_possible_nt.spliced_1586-2031.fasta \
    --start 1586 --end 2031 --only-first
  (README path; repo also contains Files/DQD_SDH/DQD_SDH1.spliced_1586-2031.fasta)

G6. TransDecoder ORF prediction (external, README):
  TransDecoder.LongOrfs / TransDecoder.Predict on spliced transcript.

G7. Manual CDS curation + UTR/protein export:
  python bin/evaluate_utrs_cds_transdecoder.py \
    -i <spliced fasta> --cds-start 131 --cds-end 1627 \
    -o Files/DQD_SDH/TransDecoder_eval --trim-cds --only-first
  Outputs: CserDQD_SDH1.1.{five_prime_UTR,CDS,three_prime_UTR,protein,qc}.fasta/txt

G8. Protein property check: ProtParam (web, README).


PHASE H: Within-species DQD/SDH diversity (bin/ + Analysis.Rmd #7-#8)
---------------------------------------------------------------------
Inputs: Files/DQD_SDH/DQD_SDH_possible_{nt,pr}.fasta

Command:
  python3 bin/align_SDH_distance_iqtree.py \
    --protein-fasta Files/DQD_SDH/DQD_SDH_possible_pr.fasta \
    --nt-fasta Files/DQD_SDH/DQD_SDH_possible_nt.fasta \
    --outdir Files/DQD_SDH/align_tree --threads 8

Processing:
  - Clustal Omega alignment per dataset
  - Gap-ignored p-distance matrix (custom Python)
  - IQ-TREE: -m MFP -bb 1000

Outputs (Files/DQD_SDH/align_tree/):
  - *.clustalo.fasta, *.dist_nogaps.tsv, *.dist_nogaps.qc.tsv
  - *.iqtree.* (including *.contree for R plotting)

Analysis.Rmd #7-#8:
  - Identity heatmaps + dendrogram -> plots/DQD_SDH_possible_{nt,pr}_identity_heatmap.png
  - Combined figure -> plots/Figure_ABCD_combined.png
  - Outgroup for tree rooting in chunk #7: CserDQD/SDH1.1, CserDQD/SDH1.2

What is reproducible inside this repository alone
-------------------------------------------------
Without raw reads and external databases, you can re-run:
  - GFF3 merge (if best-hit files present)
  - GO parsing (if emapper.annotations present)
  - DQD/SDH splice/UTR scripts
  - align_SDH_distance_iqtree.py and align_and_tree_one.py (requires clustalo,
    iqtree on PATH)
  - Analysis.Rmd figure regeneration (requires R package stack)

Suggested local workflow (partial, from stored artifacts)
---------------------------------------------------------
1) Clone repository and set working directory to repository root.

2) (Optional) Re-merge GFF3 annotation:
   python bin/gff3_annotation.py
   Note: script writes annotated_final.gff3 to CWD; move/copy to Files/ if desired.

3) (Optional) Rebuild GO tables:
   python bin/GO_analysis_from_eggnogg_data.py
   Move GO_annotation.txt to Files/ if using gff3_annotation.py as written.

4) DQD/SDH splice and gene model evaluation:
   python3 bin/splice_interval_to_fasta.py \
     -i Files/DQD_SDH/DQD_SDH_possible_nt.fasta \
     -o Files/DQD_SDH/DQD_SDH_possible_nt.spliced_1586-2031.fasta \
     --start 1586 --end 2031 --only-first

   python bin/evaluate_utrs_cds_transdecoder.py \
     -i Files/DQD_SDH/DQD_SDH_possible_nt.spliced_1586-2031.fasta \
     --cds-start 131 --cds-end 1627 \
     -o Files/DQD_SDH/TransDecoder_eval --trim-cds --only-first

5) Within-species alignment, distances, trees:
   python3 bin/align_SDH_distance_iqtree.py \
     --protein-fasta Files/DQD_SDH/DQD_SDH_possible_pr.fasta \
     --nt-fasta Files/DQD_SDH/DQD_SDH_possible_nt.fasta \
     --outdir Files/DQD_SDH/align_tree --threads 8

6) Multi-species alignment and tree:
   python3 bin/align_and_tree_one.py \
     -i Files/Alignment/For_alignment.fasta \
     -o Files/Alignment/ClustalO.aln.fa --seq-type protein --threads 8

7) Render analysis report:
   R -e 'rmarkdown::render("Analysis.Rmd")'
   Unclear from repository: whether all chunks run without manual fixes
   (e.g., outgroup_tips in chunk #10, typos pC vs pA in chunk #4).
